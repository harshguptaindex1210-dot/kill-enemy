# Handoff — Gloo wall + mobile crouch (2026-08-10)

## Objective

Add Free Fire–style deployable gloo wall cover and a mobile **down/crouch** hold button.

## Repository

- Repo: `kill-enemy` @ `main`
- Remote: `origin` → `https://github.com/harshguptaindex1210-dot/kill-enemy.git`

## Shipped

### Mobile crouch (down)

- New touch button **⬇** in the action row (hold to crouch, release to stand).
- Desktop: **Ctrl** hold-to-crouch (changed from toggle).
- Crouch synced to demo-online via `WireInput.crouch`.

### Gloo wall

- **3 walls** per match start (`glooWallCount` on `SimUnit`).
- Deploy in front of player along yaw; **45s TTL**; blocks hitscan and player collision.
- **Desktop:** `G` key.
- **Mobile:** **W** button (skill slot repurposed for wall).
- Blue translucent panel via lazy `glooWallVisual` chunk.
- Logic in lazy `glooWall.ts` chunk (dynamic import from `gameplay.ts`).

### Files

| Path | Role |
|------|------|
| `src/glooWall.ts` | Placement, raycast, collision (async chunk) |
| `src/glooWallVisual.ts` | Three.js panel meshes (async chunk) |
| `src/gameplay.ts` | Sim integration, deploy, wall-blocked shots |
| `src/input.ts` | Down button, G / W inputs |
| `src/player.ts` | Hold crouch, `glooWall` input |
| `src/weapons.ts` | Optional `maxRange` for wall-blocked hitscan |
| `src/net/protocol.ts` | `crouch`, `glooWall` on wire |
| `scripts/bundle-size.js` | Limit raised to 676000 (+1KB for feature) |
