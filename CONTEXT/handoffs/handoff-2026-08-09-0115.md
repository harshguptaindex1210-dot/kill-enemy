- **256×256** procedural albedo + **roughnessMap** per ground kind (`dirt`, `asphalt`, `sand`)
- Macro variation: grass patches, asphalt cracks, sand wind ripples
- Low quality uses **128px** textures to save GPU memory

- **Map-aware color grade** profiles (`meadow` warm/green, `city` cool/contrast, `desert` golden)
